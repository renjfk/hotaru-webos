### New Features

- Two players can share one console: link a second PSN account under Settings > PSN account and pair the console
  again with its PIN while that account is chosen, and Home shows a tile per account, marked with its initials,
  each starting the session as that player (a05ab9c, tested by @y0rit)
- A DualShock 3 over USB plays with every button, both sticks, its D-pad and its analog L2/R2; Select + Start opens
  the menu over the game (575ae2a, tested by @jura239)
- A webOS 4 TV streams through its older media API: H.264 SDR at up to 1080p60, where the app used to refuse to
  start a session, and Settings > Stream offers H.264 alone there (2e5c049, tested by @jura239)

### Improvements

- The diagnostics log names the code each controller button and axis sent and what Hotaru read from it, and the
  troubleshooting guide gives a press order, so a controller whose buttons land wrong can be reported with the
  evidence instead of a description (2f28dd2)

### Bug Fixes

- A DualShock 4 or DualSense on a webOS 11 TV reads correctly: its buttons, sticks and triggers were mismatched
  before, and its rumble and battery now work there (4655401 by @y0rit)
- LG's virtual remote input no longer passes for a controller, so the real pad is grabbed on a TV where that node
  comes first (7cf0c47 by @y0rit)
